## Bug ID: BUG-006

# Title:
Product sorting takes too long to display the sorted results

# Module:
Products / Sorting

# Environment:

Application: SauceDemo
OS: Windows
Browser: Firefox
Testing Type: Manual Testing

# Preconditions:

User is successfully logged in.
User is on the Products page.
Products are displayed.

# Steps to Reproduce:

Log in to SauceDemo with username=performance_glitch_user .
Navigate to the Products page.
Open the Sort dropdown.
Select a sorting option, for example Price (low to high).
Observe the time taken before the products are displayed in the new order.

# Expected Result:
The products should be sorted and displayed immediately or within an acceptable response time after selecting the sorting option.

# Actual Result:
The sorting operation takes approximately 8 seconds to display the sorted results.

# Severity:
Medium

# Priority:
Medium

# Status:
New

# Defect Type:
Performance
